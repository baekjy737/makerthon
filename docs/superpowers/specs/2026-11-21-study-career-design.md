# 공부 기록·다음 공부·진로 추천 — 설계 사양

2026-11-21 메이커톤 기획 피드백을 바탕으로 요구사항 인터뷰(Q1~Q14)를 거쳐 확정했다. 기존 사양 `2026-11-21-archive-system-design.md`에 더하는 내용이다.

## 목적
수업·읽은 논문·공부자료·활동·CV를 한곳에 모으고, 그 기록을 근거로 **다음에 할 공부**와 **맞는 연구실·기업·인턴**을 추천한다. 추천마다 어떤 내 기록에서 출발했는지 보여준다.

시연 흐름: 논문 메모 이슈 하나 등록 → 다음 공부 추천 → 데이터베이스에서 관련 연구실과 추천 근거 확인 → 그 연구실 지원 자료(`job` 흐름)에 기록 활용.

## 결정 사항
| # | 결정 |
|---|---|
| 범위 | 필수: 시연 흐름, 졸업학점 바로가기, 공부 계획 담기(브라우저 저장). 2순위: 기업·인턴 카드(연구실 카드와 같은 컴포넌트) |
| 추천 실행 | GitHub Actions 안에서 실행. 새 스킬 `recommend`. archive·memo 이슈가 `ready`이면 같은 실행에서 추천 파일도 갱신해 한 PR로 묶는다. 별도 라벨 `recommend`로 다시 받을 수도 있다 |
| 공부 기록 | 기존 `content/entries/`에 종류 `course` 수강 과목 · `paper` 읽은 논문 · `study` 공부자료·발표를 추가한다. 선택 필드는 `topics: []`, `course_code`. 본문 섹션은 `## 배운 점`, `## 남은 질문`. 이력서에는 들어가지 않는다 |
| 관심사 | `profile.yml`의 `interests: []` |
| 추천 결과 | `content/next/<slug>.md`(주제별 다음 공부), `content/matches/<slug>.md`(기회 카드 하나) |
| 외부 데이터 | `data/labs.json`(DGIST 교수·연구실 157명, 연구 요약, 연구실별 추천 과목, 2026 하계 인턴 참여 연구실 주제), `data/interns.json`(기업 인턴 공고 121건), `data/courses.json`(포털 교과과정표 중 과목번호·과목명·이수구분·기준학년·학점·선수과목). 출처는 LAB-INTERN-MATCH-AI 저장소(작성자 허락 필요)와 DGIST 포털 |
| 공부 계획 | 추천 카드의 [계획에 담기] → localStorage에만 저장 |
| 인턴 모집 정보 | 적합도와 따로 표시한다. 마감일이 지났으면 `마감`, 시작일 전이면 `모집 예정`, 기간 안이면 `모집 중`, 날짜나 공고 링크가 없으면 `모집 정보 확인 필요` |
| 지원 자료 | 연구실 카드의 [지원 자료 만들기] → 미리 채운 `job` 이슈. 결과는 기존 `content/applications/` |
| 비공개 | `public: false` 항목은 추천 근거(`from`)에 쓰지 않고 추천 파일에도 언급하지 않는다 |
| 시연 | 이슈를 라이브로 올리고 Action이 도는 화면을 보여준다. 기다리는 동안 같은 시나리오로 미리 반영해 둔 샘플을 설명한다 |

## 화면
- **메인(/)**: 지금의 히어로 아래에 다음을 차례로 둔다.
  - 프로필 줄: [CV 열기](`/resume`), [졸업학점 확인](DGIST 포털 → 퀵메뉴 졸업시뮬레이션)
  - 탭 [공부 기록 | 활동·포트폴리오]: 왼쪽 목록에서 고르면 오른쪽 패널이 열린다. 공부 기록은 주제별로 묶고, 패널에 배운 점·남은 질문을 보여준다. 활동은 맡은 역할과 요약을 보여준다.
  - "다음에 할 공부" 카드 3개와 "관심 분야와 맞는 기회" 카드 3개
- **다음 공부(/next, /next/<slug>)**: 이미 공부한 내용 → 다음 개념 → 이어서 볼 자료·과목 → 탐구할 연구 질문. 근거 기록을 펼쳐 볼 수 있고, [계획에 담기]가 있다.
- **기회(/match, /match/<slug>)**: 내 기록과 맞닿는 연구 주제나 직무, 지원 전 더 알아볼 점, 원본 자료 링크가 있다. 인턴은 모집 정보 배지를 붙인다. 연구실이면 [지원 자료 만들기] 버튼이 있다.
- **내 공부 계획(/plan)**: localStorage에 담은 추천 목록. 저장할 수 없는 브라우저에서는 안내를 띄운다.
