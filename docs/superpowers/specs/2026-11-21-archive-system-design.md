# DGIST AI 아카이빙 시스템 — 설계 사양

2026-11-21 요구사항 인터뷰(Q1~Q27)로 확정.

## 목적
DGIST 학생이 "Use this template"으로 각자 쓰는 템플릿 저장소. 외부 노출용 포트폴리오이자 개인 기록 창고. AI(Claude Code)가 기록·공고 분석·자소서 초안을 대신한다. 이 저장소(baekjy737/makerthon)는 메이커톤 데모이자 템플릿 1호 사용 예시.

## 결정 사항
| # | 결정 |
|---|---|
| 구조 | 학생별 템플릿 저장소. 나중에 공용 사이트(로그인+서버)로 옮길 수 있게 데이터는 파일 단위로 분리 |
| 스택 | Astro, GitHub Pages(base = 저장소 이름, 예 `/makerthon`), PWA(설치형, 오프라인은 방문한 페이지만) |

| 항목 종류 | project 프로젝트 · research 연구/논문 · award 수상 · activity 대외활동/동아리 · career 경력/인턴 · education 학력 · certificate 자격/어학 · etc 기타 |

| AI 인증 | 구독 OAuth 토큰 `CLAUDE_CODE_OAUTH_TOKEN`(`claude setup-token`). Claude GitHub App 설치 필요 |

## AI 기능
1. **아카이빙 대행** (라벨 `archive`): 메모·링크·첨부(이슈 첨부 이미지/PDF)를 받아 항목 Markdown 작성, 첨부는 `public/archive/<slug>/`에 저장. 날짜·역할 등 핵심 정보가 없으면 지어내지 않고 이슈 댓글로 되묻는다.
2. **공고 분석** (라벨 `job`): ① 요구 역량·키워드 ② 항목별 적합도 순위 + 근거 ③ 빈틈 ④ 맞춤 이력서(`/resume/<공고>`) ⑤ 자소서 문항 있으면 자소서 흐름으로. 결과는 `content/applications/<공고>/`.
3. **자소서** (라벨 `essay`): 문항·지원처 → 관련 경험 2~3개 제시 → 부족한 점(동기·역할·수치·배운 점) 3~5개 질문 → 글자 수 맞춘 초안. 받은 답은 해당 항목의 `## 자소서 재료` 섹션에 보강.
4. **메모 반영** (라벨 `memo`): 관리 페이지 메모를 해당 항목에 보강.

## 화면
- **히어로(/)**: 레퍼런스 agwo2.dev/about 뉘앙스 + apple-design 움직임. 거의 검정 배경 + 미세 도트, 굵은 condensed 대문자 3줄(이름/성(톤 낮춤)/분야, ×·대시만 포인트색), 왼쪽 사진(없으면 큰 모노그램), 상단 반투명 블러 내비 + 모노그램 로고(예 `JY.26`), 한국어 소개에서 `**굵게**` 구절만 흰색 볼드, 기록 통계 줄(기록 수·프로젝트·수상·마지막 기록 N일 전), 버튼(포트폴리오 보기 / 이력서 PDF), SCROLL 세로선은 스크롤 진행률을 1:1로 채움. 등장: 3줄 차례로 상승(오버슈트 없음), 사진은 blur+scale 해제. `prefers-reduced-motion`이면 페이드만.
- **아카이브(/archive)**: 전체 공개 항목 타임라인, 종류 필터.
- **포트폴리오(/portfolio)**: `featured: true` 항목 + 상세 페이지.
- **이력서(/resume, /resume/<공고>)**: 종류별 섹션, 요약 한 줄씩. 맞춤판은 공고 분석이 고른 항목만.
- **지원(/apply)**: 공고 목록·분석·자소서 초안.
- **관리(/manage)**: 전체 항목 목록 + 필터. 항목 클릭 → 오른쪽 메모 패널(스크림 없음, 오른쪽에서 나와 오른쪽으로 닫힘, 스프링). 메모는 브라우저 localStorage, [AI에게 보내기] = `memo` 라벨 이슈. 검색엔진 noindex.

## 개인 커스텀 (`profile.yml`)
- 색: 배경·글자·보조글자·포인트 모두 개인 지정. 기본 = 다크 배경 + 파란 포인트. 라이트/다크 토글은 없음(색 설정으로 대신).
- 폰트: 영문 디스플레이·한글 모두 지정 가능. 기본 = 한글 나눔스퀘어 네오, 영문 디스플레이 condensed(Anton).
